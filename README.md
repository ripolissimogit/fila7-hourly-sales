# Fila7 — venduto orario

Pagina pubblica aggiornata ogni ora con la variazione netta dei posti venduti dai provider. La prima lettura, o una nuova proiezione, è una baseline e compare come `n/d` finché non esiste il confronto con lo snapshot successivo.

Per cambiare i film, modifica [`config/films.json`](config/films.json). Ogni elemento richiede un `id` stabile e un `title`; `aliases` è opzionale per le varianti del titolo.
